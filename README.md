# 🎓 AI University Student Assistant

An AI-powered university student assistant designed to help students learn, revise, and prepare for exams using their own study materials.

The platform allows students to upload lecture slides, PDFs, assignments, and course materials, then interact with their content through AI-powered document-based question answering and personalized study tools.

## ✨ Key Features

- 📚 Upload lecture slides, PDFs, and study materials
- 🤖 AI-powered document-based Q&A using RAG
- 📝 Generate multiple-choice questions (MCQs)
- 🧠 Generate quizzes for self-assessment
- 🗂️ Create flashcards for revision
- 📖 Generate summaries of study materials
- 💡 Explain difficult topics in simple language
- 🎯 Generate exam preparation plans
- 💬 Maintain chat sessions and history
- 🔎 Semantic document retrieval
- 📑 Provide relevant document sources and citations
- 👤 User authentication and document isolation

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Python, FastAPI
- **Database:** SQLite / PostgreSQL
- **ORM:** SQLAlchemy
- **AI:** Large Language Models (LLMs)
- **RAG:** Retrieval-Augmented Generation
- **Embeddings:** Vector embeddings and semantic search
- **Authentication:** JWT

## 🎯 Project Goal

The goal of this project is to create an intelligent study companion that helps university students understand their course materials, practice important concepts, and prepare more effectively for examinations.
